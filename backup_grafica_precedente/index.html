Memoria Approvazioni e Skill Saltate

Quando analizzi una tua cartella con Claude o ChatGPT tramite il connettore Blooder, qui vengono salvate le skill che hai Approvato o Saltato. Quelle saltate non ti verranno più riproposte su quel progetto; se esce una nuova skill, l'agente leggerà solo la novità.

1. Collegamento diretto via MCP (Claude Desktop / Cowork, Claude Code, Cursor, Antigravity)

Copia questa configurazione nel file dei server MCP della tua applicazione AI. Non richiede chiavi API né server esterni: legge direttamente la tua libreria Blooder sul PC. 

Caricamento configurazione...

2. Collegamento per ChatGPT (Custom GPT / Azioni OpenAPI)

Blooder espone automaticamente lo schema OpenAPI pronto per ChatGPT all'indirizzo: http://127.0.0.1:8765/openapi.json. Se vuoi raggiungerlo da ChatGPT web mentre Blooder è acceso sul tuo PC, avvia un tunnel gratuito (es. cloudflared tunnel --url http://127.0.0.1:8765) e incolla l'URL seguito da /openapi.json nelle Azioni del tuo GPT.

💬 Cosa scrivere in chat dopo aver collegato la tua cartella progetto

Usa Blooder per analizzare la cartella di questo progetto: dimmi in modo semplice se nella libreria Blooder ci sono skill utili per migliorarlo o risparmiare costi, spiegami anche gli eventuali limiti onesti e chiedimi se approvo o salto ciascuna proposta.
