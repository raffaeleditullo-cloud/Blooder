Blooderskills

I pezzi in più creati e testati da noi per dare alle piattaforme di ogni settore ciò che manca alle skill standard.

Aggiungi skill

Blooder legge il repository e prepara la scheda. Poi controlli e salvi. Puoi anche compilare tutto a mano.

Crea Blooderskill

Clicca sulle skill che questo modulo potenzia, oppure lascialo vuoto se è una skill autonoma.

Istruzioni SKILL.md

Al salvataggio Blooder esporta il file in skills/<nome>/SKILL.md così puoi installarla a tuo nome.
